01 / INTERACTIVE DASHBOARD

Marketplace Sales Dashboard

An interactive MIS dashboard for exploring sales across Amazon, Flipkart, Myntra, and Meesho. Filter a fictional dataset by marketplace, category, and period to understand channel mix and SKU performance.

Why I built itBring sales, order volume, and product trends into one view for a structured performance review.

Workflow, inputs & deliverables
  1. Open the dashboard with sample sales data.
  2. Choose a marketplace and product category.
  3. Review sales, orders, trends, and product performance.

Illustrative marketplace sales records, with marketplace, category, date, and SKU information.
Outputs
Net sales, orders, average order value, units sold, trend charts, SKU rankings, and a CSV export of the filtered records.
Skills demonstrated
KPI calculation, data aggregation, interactive filtering, chart presentation, and management reporting.

This is a working browser demo using synthetic data. It does not connect to live seller accounts.

02 / PRICING AUTOMATION

Shopify Price Updater

A local web tool for reviewing and applying Shopify variant price changes from Excel or CSV. Products are matched by SKU and handle so current prices can be compared with proposed prices before submission.

Why I built itOrganize bulk price maintenance around a spreadsheet, a review step, and a record of the changes.

Workflow, inputs & deliverables
  1. Upload an Excel or CSV file with SKUs and new prices.
  2. Match products by SKU and handle, then compare old and new prices.
  3. Select the changes you want and confirm the update.
  4. Download a CSV report of the results.
Inputs
An Excel or CSV file containing product SKUs and proposed selling prices, matched with Shopify variant information.
Outputs
A comparison of current and new prices, selected variant updates through the Shopify GraphQL API, and a downloadable CSV result report.
Skills demonstrated
Node.js, API integration, spreadsheet imports, variant matching, and review-based price updates.

Includes dry-run previews and price-change thresholds. The repository is private and the tool runs locally.

03 / MARKETPLACE AUTOMATION

Amazon SSP Updater

A Python and FastAPI tool for updating Amazon standard selling prices (SSP). It resolves ASINs to seller SKUs, compares proposed changes with current listings, and checks price limits before approved submissions.

Why I built itMake bulk price changes easier to review while keeping validation and a submission history in the workflow.

Workflow, inputs & deliverables
  1. Upload ASINs and new prices in an Excel or CSV file.
  2. Find your listings, compare prices, and check price limits.
  3. Validate selected changes with Amazon, then approve updates.
  4. Download an Excel report; submissions are recorded in an audit log.
Inputs
An Excel or CSV file of ASINs and new prices, together with listing information from Amazon SP-API.
Outputs
A review of selected price changes, API validation, approved submissions, an Excel results report, and an audit log.
Skills demonstrated
Python, FastAPI, Amazon SP-API integration, ASIN-to-SKU resolution, and price validation.

Validation precedes approval and submission. The repository is private and the tool runs locally.

04 / MARKETPLACE AUTOMATION

Flipkart SSP Updater

A Python and Flask tool for managing Flipkart selling prices in bulk. Import Flipkart product identifiers (FSNs) or seller SKUs, compare current selling prices with maximum retail prices (MRP), and review selected updates.

Why I built itReplace repeated listing-by-listing price checks with a consolidated comparison and submission workflow.

Workflow, inputs & deliverables
  1. Upload product IDs or seller SKUs and new prices.
  2. Fetch current prices and maximum retail prices (MRP).
  3. Review the checks and update selected listings.
  4. Download an Excel report of the results.
Inputs
Spreadsheet rows containing FSNs or seller SKUs and proposed prices, alongside live SSP and MRP values from the Flipkart Seller API.
Outputs
A price comparison, MRP checks, a payload preview, selected listing updates, and an Excel results report.
Skills demonstrated
Python, Flask, seller API integration, spreadsheet processing, and bulk price review.

Only selected listings are included in the update step. The repository is private and the tool runs locally.

05 / INVENTORY ANALYTICS

Flipkart ATP Tracker

An inventory planning tool that reads stock and sales from Google Sheets. It calculates daily sales velocity and days of stock cover to highlight products that need replenishment, promotion, or clearance attention.

Why I built itTurn stock and sales records into a prioritized inventory action list.

Workflow, inputs & deliverables
  1. Sign in with Google to read stock and sales from your Google Sheet.
  2. Calculate daily sales and how long the available stock will last.
  3. Identify products to reorder, promote, or clear, with suggested order quantities.
  4. Filter the recommendations and export a CSV action list.
Inputs
Stock and sales records from a Google Sheet accessed through Google sign-in.
Outputs
Daily run rates, days of cover, stock alerts, suggested reorder quantities, filtered recommendations, and a CSV action list.
Skills demonstrated
JavaScript, Google Sheets API integration, stock-cover calculations, and replenishment analysis.

The source repository is public. Reading a Sheet requires Google sign-in and permission to access that Sheet.

06 / DATA COLLECTION

Web Scrapper

A Python and FastAPI product data collection tool for Amazon and Flipkart. Submit product IDs, links, or a spreadsheet, review results as they arrive, and export product information for further analysis.

Why I built itReduce repeated manual product lookups when assembling marketplace research and reporting inputs.

Workflow, inputs & deliverables
  1. Paste product IDs or links, or upload a spreadsheet.
  2. Collect product details, prices, ratings, and Flipkart stock availability.
  3. Watch results arrive, or collect compatible mobile model names from Flipkart.
  4. Download the results as Excel or CSV.
Inputs
Amazon or Flipkart product IDs and URLs, entered directly or uploaded in a spreadsheet.
Outputs
Product details, prices, ratings, Flipkart stock availability, compatible mobile model names where supported, and Excel or CSV downloads.
Skills demonstrated
Python, FastAPI, Playwright browser automation, structured data collection, and spreadsheet exports.

The source repository is public and the tool runs locally. The portfolio links to the code rather than a hosted collection service.
